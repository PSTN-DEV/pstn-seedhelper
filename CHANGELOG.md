## [4.6.0]

> Features:
- Изменили систему логов, теперь пишет в Лог-Файл дня, сохраняет последние 7 дней. Кнопка "Лог Файл" в Настройках теперь открывает папку с логами. 
- Добавили полноэкранный блок который показывает что отряд создается в текущий момент, блокирует ввод, можно отменить нажав F12. Если не удалось взять фокус Squad, отменяется создание.

> Bug fixes:
- Исправлен Баг с ограничением ФПС в Еко-режиме, теперь используется действительно мало ресурсов.
- Создание отряда частично исправлено.

## [4.5.0]

### Features
- Добавлена возможность отправки Предложений и/или Багов прям через Seed Helper.
- Добавлена функция поддержки онлайна в ночной период.
- Добавлена возможность смотреть последние изменения по кнопке текущей версии.
- Добавлена возможность выставить исходное разрешение после сида в Эко-режиме.
- Добавлена возможность остановить Сид без остановки Squad, на случай, если случайно запустили приложение с открытым Squad.
### Bug fixes:
- Исправлен Баг с порядком сида серверов.
- Исправлен Баг при краше игры который не перезапускал Squad, а использовал ссылки подключения.
- Частично попытался исправить работу создания отряда.

## [4.4.0]

### Bugs:
- Исправлена ошибка некорректного сохранения разрешения в Eco-режиме если у пользователя стоял Полноэкранный режим.
- Исправлена ошибка некорректного создания отряда.
- Исправлена ошибка кнопки "минимизировать".
- Исправлена ошибка кнопки "X", теперь вызывает предупреждение что произойдет.
- Исправлена ошибка запуска игры в стандартном режиме с отключенным звуком. (Вызывало Steam подтверждение.)
- Теперь программа будет пропускать выключенные сервера.
- Исправлены мелкие Баги в интерфейсе программы.

### Планы на v4.5:
- Добавить систему поддержки онлайна ночью.
- Добавить возможность писать Баг-репорты и Предложения прям в программе.
- Добавить систему поощрения игроков которые используют Seed Helper.
- Улучшить систему логов, автоматическая отправка ошибок при критических недочетах.
- Добавить возможность самому настраивать разрешение в Eco-режиме.
